# Muthur Command DNS plugin (CoreDNS)

中文文档: [`README.zh-CN.md`](./README.zh-CN.md)

Supervisor-managed **DNS** add-on for **Muthur Command OS**.

Built on **`ghcr.io/muthur-command/base`**; OCI labels use **`io.mcos.*`**.

## Origin

- **Upstream:** [home-assistant/plugin-dns](https://github.com/home-assistant/plugin-dns) — Home Assistant Supervisor DNS (CoreDNS) plugin container, from which this tree was ported.
- **In this repo:** **Muthur Command** keeps this fork for **Muthur Command OS**; behavior may diverge from upstream over time.
